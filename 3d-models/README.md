# 3D Printed Club Environment

> 🚧 **Work in progress.** The STL/STEP files and assembly instructions will be added here later.

The miniature club is based on the original architectural design by the construction team at DSU RCSOO Nikola Karev, Strumica. The CAD models were adapted for 3D printing by the MASSUM 2026 team.

## Parts

| Part | Description |
|------|-------------|
| **DJ booth** | Main booth with cutouts for the three ILI9341 displays and room for cables |
| **Bar counter** | Club bar with mounting points for the stage LEDs |
| **Tables** | Audience tables |
| **Sliding walls** | Wall panels, tracks, gear system and mounts for the 28BYJ-48 stepper motors and limit switches |
